---
title: "Obter Incidente"
openapi: "GET /incidents/{name}"
description: "Retorna os detalhes completos de um incidente específico"
icon: "magnifying-glass"
---

<ParamField path="name" type="string" required>
  Nome do recurso Issue (ex.: `payment-service-oom-kill-1773933600`). O id curto `INC-YYYYMMDD-NNN` é só o label `platform.chatcli.io/inc-id`, não o nome.
</ParamField>

<ParamField query="namespace" type="string">
  Namespace do incidente. Se omitido, todos os namespaces são pesquisados e o primeiro incidente com esse nome é retornado.
</ParamField>

`spec` e `status` trazem o mesmo objeto de incidente (os campos de [Listar Incidentes](/pt/reference/api/list-incidents)); `resourceMeta` traz os metadados do Kubernetes, incluindo as annotations. A análise de IA não vem embutida — busque-a com [Obter AI Insight](/pt/reference/api/get-aiinsight) (`<name>-insight`).
