---
title: "Correlações da Federação"
openapi: "GET /federation/correlations"
description: "Retorna as correlações de issues entre clusters lidas das annotations dos Issues"
icon: "diagram-project"
---

Role mínima: `viewer`. Não recebe parâmetros. Lista os Issues deste cluster que têm a annotation `platform.chatcli.io/correlation-id`, um item por ID de correlação distinto.

## Campos da correlação

| Campo | Origem |
|-------|--------|
| `correlationId` | Annotation `platform.chatcli.io/correlation-id` |
| `issue`, `namespace`, `severity`, `signalType` | O primeiro Issue encontrado com esse ID |
| `correlatedClusters` | Valor bruto da annotation `platform.chatcli.io/correlated-clusters` |
| `elevated` | Annotation `platform.chatcli.io/elevated-severity` igual a `"true"` |
| `cascade` | Annotation `platform.chatcli.io/cascade-detected` igual a `"true"` |

<Warning>
**Limitação conhecida: este endpoint retorna uma lista vazia nas versões atuais.** O controller de federação não grava as annotations que o endpoint lê. Quando o mesmo `signalType` está ativo em 3 ou mais clusters, `CorrelateAcrossClusters` grava `platform.chatcli.io/cross-cluster-correlation` (`xcluster-<id>`) e `platform.chatcli.io/affected-clusters` (uma contagem) e eleva `spec.severity` para `critical`; `DetectCascade` grava `platform.chatcli.io/cascade-detected`, `cascade-source-cluster` e `cascade-source-issue`. Nada grava `correlation-id`, `correlated-clusters` ou `elevated-severity`, então todo Issue é ignorado. Até isso ser corrigido, consulte as correlações diretamente:

```bash
kubectl get issues -A -o json | jq -r '.items[]
  | select(.metadata.annotations["platform.chatcli.io/cross-cluster-correlation"] != null
        or .metadata.annotations["platform.chatcli.io/cascade-detected"] == "true")
  | [.metadata.namespace, .metadata.name, .spec.severity,
     .metadata.annotations["platform.chatcli.io/cross-cluster-correlation"] // "-",
     .metadata.annotations["platform.chatcli.io/affected-clusters"] // "-",
     .metadata.annotations["platform.chatcli.io/cascade-source-cluster"] // "-"] | @tsv'
```
</Warning>
