---
title: "Obter Timeline do Incidente"
openapi: "GET /incidents/{name}/timeline"
description: "Retorna a timeline de eventos registrada no PostMortem do incidente"
icon: "timeline"
---

<ParamField path="name" type="string" required>
  Nome do recurso Issue (ex.: `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="namespace" type="string">
  Só procura o PostMortem neste namespace. Se omitido, todos os namespaces são pesquisados.
</ParamField>

A timeline é lida do **PostMortem** cujo `issueRef` é este incidente (`status.timeline`). O PostMortem é gerado quando um RemediationPlan do incidente termina (resolvido ou contido), então um incidente ainda em análise ou remediação, escalado sem plano concluído, ou resolvido manualmente **ainda não tem timeline** e retorna `404`.

Os valores de `type` gravados pelo operator são `detected`, `action_executed`, `action_failed` e `resolved`; no modo agêntico cada passo vira um evento cujo `detail` inclui o raciocínio da IA. A lista não é paginada (`page` é sempre 1).

```json Response 200
    {
      "timestamp": "2026-03-19T15:20:00Z",

    },
    {
      "timestamp": "2026-03-19T15:24:10Z",

      "detail": "AdjustResources: memory limit raised to 1Gi"
    },

    }
  ]

```
