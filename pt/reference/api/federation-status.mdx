---
title: "Status da Federação"
openapi: "GET /federation/status"
description: "Retorna a contagem de clusters conectados, degradados e desconectados e o número de issues ativos"
icon: "network-wired"
---

Role mínima: `viewer`. Não recebe parâmetros. `GET /api/v1/federation` (sem sufixo) devolve a mesma resposta.

- `totalClusters`, `connectedClusters`, `disconnectedClusters`: a partir do campo `status.connected` de cada ClusterRegistration (um registro sem status conta como desconectado)
- `degradedClusters`: registros conectados cuja condição `Degraded` é `True` (alguns nós não estão Ready); eles também entram em `connectedClusters`
- `totalActiveIssues`: Issues **deste** cluster, em qualquer namespace, cujo estado não é `Resolved` nem `Failed` (Issues de clusters remotos não entram na conta)

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "FederationStatus",
  "spec": {
    "totalClusters": 5,
    "connectedClusters": 4,
    "degradedClusters": 1,
    "disconnectedClusters": 1,
    "totalActiveIssues": 7
  }
}
```
</ResponseExample>
