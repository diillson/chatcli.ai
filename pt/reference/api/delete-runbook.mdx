---
title: "Excluir Runbook"
openapi: "DELETE /runbooks/{name}"
description: "Exclui um recurso Runbook. Exige a role admin."
icon: "trash"
---

<ParamField path="name" type="string" required>
  Nome do runbook (ex.: `disk-cleanup`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Namespace do runbook (outros namespaces não são pesquisados)
</ParamField>

Exige a role **`admin`**. O runbook é excluído sem nenhuma checagem de uso: RemediationPlans já criados a partir dele têm a própria cópia das ações e não são afetados.

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "Status",
  "status": "deleted",
  "name": "disk-cleanup"
}
```
</ResponseExample>

<ResponseExample>
```json Response 404
{
  "apiVersion": "v1",
  "kind": "Error",
  "error": "Not Found",
  "code": 404,
  "message": "runbook not found: runbooks.platform.chatcli.io \"disk-cleanup\" not found"
}
```
</ResponseExample>
