---
title: "Top Recursos de Analytics"
openapi: "GET /analytics/top-resources"
description: "Retorna os recursos com mais incidentes, ordenados pela contagem, para achar áreas que precisam de correções estruturais"
icon: "ranking-star"
---

<ParamField query="from" type="string">
  Início da janela, RFC 3339 (ex.: `2026-03-01T00:00:00Z`). Um valor inválido é ignorado.
</ParamField>

<ParamField query="to" type="string">
  Fim da janela, RFC 3339.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Número máximo de recursos retornados. Valores não positivos ou inválidos voltam para 10.
</ParamField>

Role mínima: `viewer`. Cobre todos os namespaces. Os Issues criados na janela são agrupados pelo recurso alvo (`kind`, `name`, `namespace`) e ordenados por `incidentCount`, do maior para o menor. `lastIncident` é o horário de criação do Issue mais recente daquele recurso.
