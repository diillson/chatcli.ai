<ParamField query="namespace" type="string">
  Filtrar por namespace do Kubernetes (omita para todos os namespaces)
</ParamField>

<ParamField query="state" type="string">
  Filtrar por estado (sem diferenciar maiúsculas): `Pending`, `WaitingApproval`, `Executing`, `Verifying`, `Completed`, `Failed`, `RolledBack`
</ParamField>

<ParamField query="issue" type="string">
  Filtrar pelo nome do Issue pai (ex.: `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página para paginação
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Itens por página (máximo 100)
</ParamField>

## Modos de Remediação

Cada plano opera em um dos dois modos:

- **Modo Runbook** (`agenticMode: false`): Executa uma sequência pré-definida de ações a partir de um runbook correspondente
- **Modo Agêntico** (`agenticMode: true`): Remediação passo a passo orientada por IA, onde o LLM propõe ações, observa resultados e decide os próximos passos

Os planos se chamam `<issue>-plan-<tentativa>`. Campos opcionais vazios (`result`, `actions`, `startedAt`, `completedAt`) são omitidos.
