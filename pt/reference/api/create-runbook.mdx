---
title: "Criar Runbook"
openapi: "POST /runbooks"
description: "Cria um novo recurso Runbook"
icon: "plus"
---

<ParamField body="name" type="string" required>
  Nome do runbook (um nome de recurso do Kubernetes, ex.: `disk-cleanup`)
</ParamField>

<ParamField body="namespace" type="string" default="default">
  Namespace onde o runbook será criado
</ParamField>

<ParamField body="description" type="string">
  Objetivo do runbook
</ParamField>

<ParamField body="trigger" type="object" required>
  Quando o runbook se aplica. Os três campos são obrigatórios no CRD.
  <Expandable title="Propriedades do trigger">
    <ParamField body="signalType" type="string" required>
      Sinal da anomalia, ex.: `oom_kill`, `crashloop_backoff`, `error_rate`, `latency`, `pod_restart`, `cpu_high`, `memory_high`, `disk_pressure`, `image_pull_error` (lista completa no enum do CRD Anomaly)
    </ParamField>
    <ParamField body="severity" type="string" required>
      `critical`, `high`, `medium` ou `low`
    </ParamField>
    <ParamField body="resourceKind" type="string" required>
      Kind do recurso afetado, ex.: `Deployment`, `StatefulSet`, `DaemonSet`, `Job`, `CronJob`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="steps" type="object[]" required>
  Passos em ordem
  <Expandable title="Propriedades do passo">
    <ParamField body="name" type="string" required>
      Nome do passo
    </ParamField>
    <ParamField body="action" type="string" required>
      Tipo de ação de remediação, ex.: `AdjustResources`, `RestartDeployment`, `ScaleDeployment`, `RollbackDeployment`, `ExecDiagnostic`
    </ParamField>
    <ParamField body="description" type="string">
      Por que o passo é necessário e o que ele faz
    </ParamField>
    <ParamField body="params" type="object">
      Parâmetros chave/valor (strings) da ação (ex.: `{"memory_limit": "1Gi"}`, `{"replicas": "5"}`)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="maxAttempts" type="integer" default="3">
  Número máximo de tentativas de remediação; 0 ou omitido significa 3
</ParamField>

<ParamField body="labels" type="object">
  Labels do Kubernetes para o Runbook
</ParamField>

A resposta é `201 Created`, com o runbook em `spec` e os metadados em `resourceMeta`. `name` ausente ou JSON malformado retornam `400`; uma falha da API do Kubernetes retorna a mensagem do API server com o status correspondente: `409` só quando já existe um runbook com esse nome, `422` quando o API server rejeita o objeto (valor fora dos enums do CRD, campo obrigatório ausente), `403` quando o operator não tem permissão para criá-lo e `500` nos demais casos.

<RequestExample>
```json runbook.json
{
  "name": "disk-cleanup",
  "namespace": "production",
  "description": "Free disk space when a StatefulSet reports disk pressure",
  "trigger": {
    "signalType": "disk_pressure",
    "severity": "medium",
    "resourceKind": "StatefulSet"
  },
  "steps": [
    {
      "name": "diagnose",
      "action": "ExecDiagnostic",
      "description": "Check filesystem usage",
      "params": {
        "command": "df -h"
      }
    },
    {
      "name": "restart-pod",
      "action": "RestartStatefulSetPod",
      "description": "Restart the affected pod"
    }
  ],
  "labels": {
    "team": "storage"
  }
}
```

```bash curl
curl -X POST -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d @runbook.json http://localhost:8090/api/v1/runbooks
```
</RequestExample>
