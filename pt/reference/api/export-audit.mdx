---
title: "Exportar Auditoria"
openapi: "GET /audit/export"
description: "Baixa os registros AuditEvent filtrados como um arquivo JSON para compliance e ingestão em SIEM"
icon: "file-export"
---

<ParamField query="namespace" type="string">
  Filtrar pelo namespace do AuditEvent. Sem ele, lista todos os namespaces.
</ParamField>

<ParamField query="type" type="string">
  Filtrar por `eventType` (comparação exata), ex.: `issue_created`, `issue_resolved`, `issue_escalated`, `issue_contained`, `remediation_started`, `remediation_completed`, `remediation_failed`, `approval_requested`, `approval_approved`, `approval_rejected`, `approval_expired`, `notification_sent`, `slo_violation`, `sla_breach`
</ParamField>

<ParamField query="severity" type="string">
  Filtrar por severidade: `info`, `warning`, `critical`
</ParamField>

<ParamField query="resource" type="string">
  Filtrar pelo **nome** do recurso afetado (comparação exata com `resourceName`)
</ParamField>

<ParamField query="from" type="string">
  Apenas eventos a partir deste timestamp RFC 3339 (`spec.timestamp`, ou o horário de criação na falta dele)
</ParamField>

<ParamField query="to" type="string">
  Apenas eventos até este timestamp RFC 3339
</ParamField>

Role mínima: `viewer`. Aceita os mesmos filtros de [Listar eventos de auditoria](/pt/reference/api/list-audit), mas devolve **todos** os eventos que casam em uma única resposta `200` síncrona, sem paginação. O corpo é somente JSON (não há CSV, opção `format` nem job assíncrono de exportação), enviado com `Content-Disposition: attachment; filename=audit-events-<YYYYMMDD-HHMMSS>.json`.

```bash
curl -s -H "X-API-Key: $CHATCLI_API_KEY" \
  "http://localhost:8090/api/v1/audit/export?namespace=production&from=2026-03-01T00:00:00Z" \
  -o audit-events.json
```
