---
title: "Status Global dos Clusters"
openapi: "GET /clusters/global-status"
description: "Retorna a contagem de clusters conectados e offline de todos os ClusterRegistrations, junto com a lista de clusters"
icon: "globe"
---

Role mínima: `viewer`. Não recebe parâmetros. O endpoint lista todos os ClusterRegistrations de todos os namespaces e conta:

- `totalClusters`: todos os registros
- `healthyClusters`: registros com `status.connected: true`
- `offlineClusters`: todos os demais
- `degradedClusters`: sempre `0` na versão atual (nenhum estado degradado é calculado)

`clusters` traz cada registro com os campos descritos em [Listar Clusters](/pt/reference/api/list-clusters); vem `null` quando não há registros. Não há agregados de nós, recursos, SLOs ou incidentes aqui; para totais de issues, use [Status da federação](/pt/reference/api/federation-status).
