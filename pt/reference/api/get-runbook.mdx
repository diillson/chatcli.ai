---
title: "Obter Runbook"
openapi: "GET /runbooks/{name}"
description: "Retorna um recurso Runbook"
icon: "book-open"
---

<ParamField path="name" type="string" required>
  Nome do runbook (ex.: `oomkill-standard`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Namespace do runbook. O padrão é `default` (outros namespaces não são pesquisados).
</ParamField>

`spec` traz o runbook no mesmo formato de [Listar Runbooks](/pt/reference/api/list-runbooks); `resourceMeta` traz os metadados do Kubernetes (uid, labels, annotations). Não há `status`.

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "Runbook",
  "spec": {
    "name": "oomkill-standard",
    "namespace": "production",
    "description": "Standard remediation for OOMKill: raise the memory limit and restart the Deployment",
    "trigger": {
      "signalType": "oom_kill",
      "severity": "high",
      "resourceKind": "Deployment"
    },
    "steps": [
      {
        "name": "raise-memory-limit",
        "action": "AdjustResources",
        "description": "Raise the container memory limit",
        "params": {
          "memory_limit": "1Gi"
        }
      },
      {
        "name": "restart",
        "action": "RestartDeployment",
        "description": "Restart pods to reclaim memory"
      }
    ],
    "maxAttempts": 3,
    "creationTimestamp": "2026-01-10T08:00:00Z"
  },
  "resourceMeta": {
    "name": "oomkill-standard",
    "namespace": "production",
    "uid": "3c4d5e6f-7a8b-4c9d-8e0f-1a2b3c4d5e6f",
    "creationTimestamp": "2026-01-10T08:00:00Z"
  }
}
```
</ResponseExample>

<ResponseExample>
```json Response 404
{
  "apiVersion": "v1",
  "kind": "Error",
  "error": "Not Found",
  "code": 404,
  "message": "runbook not found: runbooks.platform.chatcli.io \"oomkill-standard\" not found"
}
```
</ResponseExample>
