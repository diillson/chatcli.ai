---
title: "Listar PostMortems"
openapi: "GET /postmortems"
description: "Retorna a lista de postmortems gerados automaticamente pela plataforma"
icon: "list"
---

<ParamField query="namespace" type="string">
  Filtrar por namespace Kubernetes. Sem ele, lista todos os namespaces.
</ParamField>

<ParamField query="severity" type="string">
  Filtrar por severidade: `critical`, `high`, `medium`, `low`
</ParamField>

<ParamField query="state" type="string">
  Filtrar por estado: `Open`, `InReview`, `Closed` (comparação exata)
</ParamField>

<ParamField query="from" type="string">
  Apenas postmortems criados a partir deste timestamp RFC 3339 (ex.: `2026-03-01T00:00:00Z`)
</ParamField>

<ParamField query="to" type="string">
  Apenas postmortems criados até este timestamp RFC 3339
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Itens por página (máximo 100)
</ParamField>

Role mínima: `viewer`. Um PostMortem se chama `pm-<nome do issue>` e cada item tem os mesmos campos de [Obter PostMortem](/pt/reference/api/get-postmortem). Um valor de `from`/`to` que não seja RFC 3339 válido é ignorado.
