  Filtrar por namespace do Kubernetes (omita para todos os namespaces)
</ParamField>

<ParamField query="issue" type="string">
  Filtrar pelo nome do Issue pai (ex.: `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página para paginação
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Itens por página (máximo 100)
</ParamField>

## O Que São AI Insights?

Quando um incidente entra em análise, o operator cria um recurso **AIInsight** para ele, chamado `<issue>-insight`, e o preenche com a análise devolvida pelo servidor ChatCLI ao qual está conectado. `provider` e `model` são copiados da primeira Instance pronta (`model` fica vazio quando a Instance não define um). Isso inclui:

- **Análise de causa raiz** com score de confiança (`confidence`, 0.0–1.0)
- **Recomendações** em formato legível por humanos
- **Ações sugeridas** com parâmetros concretos (ex.: `ScaleDeployment` com `replicas: "5"`)
- **Dados de enriquecimento** (cada um só aparece quando coletado): análise de logs, métricas Prometheus, código-fonte, contexto GitOps, análise de cascata e previsão de raio de explosão

Este endpoint é essencial para entender **como a IA raciocinou** sobre cada incidente, especialmente quando incidentes são escalados para operadores humanos.
