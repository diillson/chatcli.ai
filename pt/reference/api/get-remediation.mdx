---
title: "Obter Remediação do Incidente"
openapi: "GET /incidents/{name}/remediation"
description: "Retorna os planos de remediação criados para um incidente, com o estado de execução"
icon: "wrench"
---

<ParamField path="name" type="string" required>
  Nome do recurso Issue (ex.: `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="namespace" type="string">
  Só planos deste namespace. Se omitido, retorna os planos de todos os namespaces cujo `issueRef` corresponde ao nome.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Número da página
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Itens por página (máximo 100)
</ParamField>

Retorna todo RemediationPlan cujo `issueRef` é este incidente — um por tentativa (`<issue>-plan-1`, `<issue>-plan-2`, …) — no mesmo formato de item de [Listar Remediações](/pt/reference/api/list-remediations). Um incidente ainda sem plano retorna lista vazia (`totalCount: 0`), não `404`; o incidente em si não é consultado. Para evidências, dados de rollback e o histórico agêntico de um plano, use [Obter Plano de Remediação](/pt/reference/api/get-remediation-detail).
