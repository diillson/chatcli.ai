---
title: "Obter Política"
openapi: "GET /policies/{kind}/{name}"
description: "Retorna um ApprovalPolicy, NotificationPolicy, EscalationPolicy ou IncidentSLA com spec e status brutos"
icon: "file-lines"
---

<ParamField path="kind" type="string" required>
  `approval`, `notification`, `escalation` ou `sla`
</ParamField>

<ParamField path="name" type="string" required>
  Nome da política
</ParamField>

<ParamField query="namespace" type="string">
  Namespace da política
</ParamField>

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "IncidentSLA",
  "spec": { "severity": "critical", "responseTime": "15m", "resolutionTime": "1h" },
  "status": { "totalIssuesTracked": 14, "totalViolations": 2, "activeViolations": 1, "compliancePercentage": 85.7 }
}
```
</ResponseExample>
