---
title: "Obter Política"
openapi: "GET /policies/{kind}/{name}"
description: "Retorna um ApprovalPolicy, NotificationPolicy, EscalationPolicy ou IncidentSLA com spec e status brutos"
icon: "file-lines"
---

<ParamField path="kind" type="string" required>
  `approval`, `notification`, `escalation` ou `sla`
</ParamField>

<ParamField path="name" type="string" required>
  Nome da política
</ParamField>

<ParamField query="namespace" type="string">
  Namespace da política. Se omitido, todos os namespaces são pesquisados e a primeira política com esse nome é retornada.
</ParamField>

Role mínima: `viewer`. Somente leitura: qualquer método diferente de `GET` retorna `405`. `spec` e `status` são os campos do CRD sem alteração; `resourceMeta` traz nome, namespace, UID, horário de criação, labels e annotations.

<ResponseExample>

```json Response 200
  "kind": "IncidentSLA",
  "spec": {

    "responseTime": "15m",
    "resolutionTime": "1h"
  },
  "status": {
    "activeViolations": 1,
    "totalViolations": 2,
    "compliancePercentage": 85.7,
    "totalIssuesTracked": 14
  },
  "resourceMeta": {
    "name": "critical-sla",

```
