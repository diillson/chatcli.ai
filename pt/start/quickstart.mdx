Esta página leva você do zero a um ChatCLI funcionando. Cada passo aponta para o guia completo quando você quiser os detalhes.

<Steps>
  <Step title="Instale o ChatCLI">
    <Tabs>
      <Tab title="Homebrew">
        ```bash
        brew tap diillson/chatcli && brew install chatcli
        ```
      </Tab>
      <Tab title="go install">
        ```bash
        go install github.com/diillson/chatcli@latest
        ```

        Requer Go 1.27 ou mais novo.
      </Tab>
      <Tab title="Binário">
        Baixe o binário da sua plataforma em [Releases](https://github.com/diillson/chatcli/releases) e depois:

        ```bash
        chmod +x chatcli && sudo mv chatcli /usr/local/bin/
        ```
      </Tab>
      <Tab title="Docker">
        ```bash
        docker pull ghcr.io/diillson/chatcli:latest
        ```
      </Tab>
    </Tabs>

    Confira se ele roda:

    ```bash
    chatcli --version
    ```

    Build a partir do código-fonte, Helm e todas as outras opções: [Instalação](/pt/start/installation).
  </Step>

  <Step title="Conecte um provedor">
    O ChatCLI lê as configurações de um arquivo `.env`: primeiro `./.env`, depois `~/.chatcli/.env` e por fim `~/.env`. Escolha um provedor e adicione a chave:

    <CodeGroup>
    ```bash OpenAI
    echo 'LLM_PROVIDER=OPENAI' > .env
    echo 'OPENAI_API_KEY=sk-xxx' >> .env
    ```

    ```bash Claude
    echo 'LLM_PROVIDER=CLAUDEAI' > .env
    echo 'ANTHROPIC_API_KEY=sk-ant-xxx' >> .env
    ```

    ```bash Gemini
    echo 'LLM_PROVIDER=GOOGLEAI' > .env
    echo 'GOOGLEAI_API_KEY=AIza...' >> .env
    ```

    ```bash Ollama (local)
    echo 'LLM_PROVIDER=OLLAMA' > .env
    echo 'OLLAMA_BASE_URL=http://localhost:11434' >> .env
    echo 'OLLAMA_MODEL=llama3.1' >> .env
    ```

    ```bash OpenRouter
    echo 'LLM_PROVIDER=OPENROUTER' > .env
    echo 'OPENROUTER_API_KEY=sk-or-xxx' >> .env
    ```
    </CodeGroup>

    <Tip>
    Tem plano ChatGPT, Claude ou GitHub Copilot? Pule a chave: inicie o ChatCLI e rode `/auth login openai-codex`, `/auth login anthropic` ou `/auth login github-copilot`. Veja [Autenticação OAuth](/pt/providers/oauth-authentication).
    </Tip>

    Cada provedor tem um modelo default; defina `<PROVEDOR>_MODEL` para escolher outro. Os catorze provedores e seus modelos estão em [Modelos suportados](/pt/providers/supported-models).
  </Step>

  <Step title="Faça seu primeiro chat">
    ```bash
    chatcli
    ```

    Digite uma pergunta e tecle Enter. Dentro do prompt, `/config` mostra o provedor e o modelo ativos, `/switch` troca os dois sem reiniciar e `/help` lista todos os comandos.
  </Step>

  <Step title="Dê o contexto do seu projeto">
    Os comandos `@` trazem o seu ambiente para dentro do prompt:

    ```text
    @file ./cmd explique como a CLI inicializa
    @git escreva a mensagem de commit das mudanças staged
    @command go test ./... > por que isso está falhando?
    ```

    Mais em [Comandos de contexto](/pt/usage/context-commands).
  </Step>

  <Step title="Passe uma tarefa de código">
    O coder mode lê, edita, roda testes e faz rollback em loop, pedindo confirmação antes de qualquer coisa arriscada:

    ```text
    /coder corrija os testes que estão falhando
    ```

    Veja o [Coder mode](/pt/usage/coder-mode) para o fluxo de aprovação e as regras de segurança.
  </Step>
</Steps>
