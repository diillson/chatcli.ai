---
title: "Update Runbook"
openapi: "PUT /runbooks/{name}"
description: "Replaces the definition of an existing Runbook"
icon: "pen-to-square"
---

<ParamField path="name" type="string" required>
  Runbook name (e.g., `oomkill-standard`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Namespace of the runbook (other namespaces are not searched)
</ParamField>

This is a **replace**, not a patch: `description`, `trigger` and `steps` are always overwritten with what you send (an omitted field becomes empty, and an empty `trigger` is rejected by the CRD). Only `maxAttempts` (when greater than 0) and `labels` (when present) are optional. `name` and `namespace` in the body are ignored.

<ParamField body="description" type="string">
  Purpose of the runbook
</ParamField>

<ParamField body="trigger" type="object" required>
  When the runbook applies. All three fields are required by the CRD.
  <Expandable title="Trigger properties">
    <ParamField body="signalType" type="string" required>
      Anomaly signal, e.g. `oom_kill`, `crashloop_backoff`, `error_rate`, `latency`, `pod_restart`, `cpu_high`, `memory_high`, `disk_pressure`, `image_pull_error` (full list in the Anomaly CRD enum)
    </ParamField>
    <ParamField body="severity" type="string" required>
      `critical`, `high`, `medium` or `low`
    </ParamField>
    <ParamField body="resourceKind" type="string" required>
      Kind of the affected resource, e.g. `Deployment`, `StatefulSet`, `DaemonSet`, `Job`, `CronJob`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="steps" type="object[]" required>
  Ordered steps (replaces the whole list)
  <Expandable title="Step properties">
    <ParamField body="name" type="string" required>
      Step name
    </ParamField>
    <ParamField body="action" type="string" required>
      Remediation action type, e.g. `AdjustResources`, `RestartDeployment`, `ScaleDeployment`, `RollbackDeployment`, `ExecDiagnostic`
    </ParamField>
    <ParamField body="description" type="string">
      Why the step is needed and what it does
    </ParamField>
    <ParamField body="params" type="object">
      String key/value parameters for the action (e.g. `{"memory_limit": "1Gi"}`, `{"replicas": "5"}`)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="maxAttempts" type="integer" default="unchanged">
  New maximum number of remediation attempts; ignored when 0 or omitted
</ParamField>

<ParamField body="labels" type="object">
  Replaces all labels when provided; existing labels are kept when omitted
</ParamField>

    }
  ]
