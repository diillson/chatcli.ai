---
title: "Analytics MTTD"
openapi: "GET /analytics/mttd"
description: "Returns Mean Time To Detect per day, computed from Issue timestamps"
icon: "stopwatch"
---

<ParamField query="from" type="string">
  Start of the window, RFC 3339 (e.g., `2026-03-01T00:00:00Z`). An unparseable value is ignored.
</ParamField>

<ParamField query="to" type="string">
  End of the window, RFC 3339.
</ParamField>

Minimum role: `viewer`. Covers every namespace.

For each Issue created in the window, except Issues induced by a chaos experiment (label `platform.chatcli.io/source: chaos-experiment`), the detection time is `status.detectedAt − metadata.creationTimestamp` (0 when `detectedAt` is empty or earlier). Issues are grouped by the day they were created (`YYYY-MM-DD`, ascending). In each item, `value` is the mean in **seconds** and `count` the number of Issues that day.

Because an Issue is created when the operator reacts to an anomaly, this measures the gap between the Issue and its detection mark, not the time from the underlying fault to detection. Values near 0 are expected.
