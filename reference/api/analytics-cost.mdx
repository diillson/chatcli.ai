---
title: "Analytics Cost"
openapi: "GET /analytics/cost"
description: "Returns the LLM spend the controllers booked per incident — total cost, incident count and cost per incident for a namespace and window"
icon: "coins"
---

<ParamField query="namespace" type="string">
  Kubernetes namespace whose ledger to read. Empty aggregates every namespace's ledger.
</ParamField>

<ParamField query="from" type="string">
  Start date in RFC3339 format
</ParamField>

<ParamField query="to" type="string">
  End date in RFC3339 format (default: now). The window defaults to 30 days.
</ParamField>

## Summary Fields

| Field | Description |
|-------|-------------|
| `periodStart` / `periodEnd` | Window boundaries |
| `totalLLMCost` | Sum of every incident's `estimatedCostUSD` booked inside the window (entries without a `recordedAt`, written before the stamp existed, always count) |
| `incidentCount` | Incidents with a ledger entry in the window |
| `costPerIncident` | `totalLLMCost / incidentCount` |

The ledger lives in one `chatcli-cost-ledger` ConfigMap per namespace; see [Capacity, Noise and Cost](/features/aiops/capacity-cost#cost-tracker) for its format and the pricing override.
