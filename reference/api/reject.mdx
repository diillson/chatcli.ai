---
title: "Reject Request"
openapi: "POST /approvals/{name}/reject"
description: "Rejects an approval request, preventing the remediation from being executed"
icon: "circle-xmark"
---

<ParamField path="name" type="string" required>
  Approval request name (e.g., `approval-payment-service-oom-kill-1773933600-plan-1`)
</ParamField>

<ParamField query="namespace" type="string">
  Kubernetes namespace. When omitted, every namespace is searched (first match).
</ParamField>

<ParamField body="approver" type="string" required>
  Name of the person rejecting, recorded next to the identity of the API key. An empty value returns `400`.
</ParamField>

<ParamField body="reason" type="string">
  Reason for the rejection
</ParamField>

The call records **one decision** on a `Pending` request, the same way the `platform.chatcli.io/reject` annotation does: it appends an entry to `status.decisions` with the approver, the reason and a timestamp. It never sets `status.state` itself. The ApprovalReconciler then evaluates the decisions: any rejection rejects the request, immediately and regardless of the change window, and the RemediationPlan waiting on it is marked `Failed` with the result `Approval rejected by <approver>: <reason>`. The response is returned right after the decision is recorded, so it usually still shows `Pending`, with the new entry in `decisions` and in `rejectedBy`. The item is returned in `spec` and `status` alike, plus `resourceMeta`.

- **Approver identity.** The approver is stored as `<approver> (api-key: <identity>)`, where the identity is the `name` of the API key entry, else its `description`, else a `key-<hash>` fingerprint (`dev-mode` in dev mode). The typed name is trimmed, control characters are dropped, and it is cut at 128 characters.
- **One decision per key.** The same key cannot decide twice on a request.
- **`409`** when the request is no longer `Pending` (already approved, rejected or expired), or when the same key already recorded a decision on it.

```json Request

  "reason": "prefer tuning the HPA first"

```
