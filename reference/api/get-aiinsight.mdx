---
title: "Get AI Insight"
openapi: "GET /aiinsights/{name}"
description: "Returns the complete AI analysis for a specific insight, including all enrichment contexts and suggested actions"
icon: "lightbulb"
---

<ParamField path="name" type="string" required>
  AI insight name, `<issue>-insight` (e.g., `payment-service-oom-kill-1773933600-insight`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Kubernetes namespace. Defaults to `default` (it does not search other namespaces), so pass the insight's namespace explicitly.
</ParamField>

## Response Fields

`spec` carries the full insight item (the fields of [List AI Insights](/reference/api/list-aiinsights), including `issueRef`, `provider` and `model`); `status` is the resource's raw Kubernetes status, with the analysis fields below.

| Field | Description |
|-------|-------------|
| `analysis` | AI-generated root cause analysis text |
| `confidence` | Confidence score from 0.0 to 1.0 |
| `recommendations` | Human-readable suggestions |
| `suggestedActions` | Concrete actions with type and parameters |
| `logAnalysis` | Structured findings from pod log analysis |
| `metricsContext` | Prometheus metric data correlated with the incident |
| `sourceCodeContext` | Relevant source code snippets from the app repository |
| `gitOpsContext` | Helm/ArgoCD/Flux status at time of analysis |
| `cascadeAnalysis` | Cross-service cascade failure analysis |
| `blastRadiusPrediction` | Predicted impact of suggested remediation actions |
