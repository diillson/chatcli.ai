---
title: "Analytics Top Resources"
openapi: "GET /analytics/top-resources"
description: "Returns the most incident-prone resources, sorted by incident count, to find problem areas that need structural fixes"
icon: "ranking-star"
---

<ParamField query="from" type="string">
  Start of the window, RFC 3339 (e.g., `2026-03-01T00:00:00Z`). An unparseable value is ignored.
</ParamField>

<ParamField query="to" type="string">
  End of the window, RFC 3339.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Maximum number of resources to return. Non-positive or invalid values fall back to 10.
</ParamField>

Minimum role: `viewer`. Covers every namespace. Issues created in the window are grouped by their target resource (`kind`, `name`, `namespace`) and sorted by `incidentCount`, highest first. `lastIncident` is the creation time of the newest Issue for that resource.
