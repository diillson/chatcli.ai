---
title: "Global Cluster Status"
openapi: "GET /clusters/global-status"
description: "Returns healthy, degraded and offline counts for every ClusterRegistration, plus the cluster list"
icon: "globe"
---

Minimum role: `viewer`. Takes no parameters. The endpoint lists every ClusterRegistration in every namespace and counts:

- `totalClusters`: all registrations
- `healthyClusters`: connected registrations (`status.connected: true`) whose `Degraded` condition is not `True`
- `degradedClusters`: connected registrations whose `Degraded` condition is `True` (some nodes are not Ready)
- `offlineClusters`: registrations that are not connected

`clusters` holds each registration with the fields described in [List Clusters](/reference/api/list-clusters); it is `null` when there are no registrations. There are no node, resource, SLO or incident aggregates here; for issue totals use [Federation Status](/reference/api/federation-status).
