---
title: "Federation Status"
openapi: "GET /federation/status"
description: "Returns connected and disconnected cluster counts and the number of active issues"
icon: "network-wired"
---

Minimum role: `viewer`. Takes no parameters. `GET /api/v1/federation` (no suffix) returns the same response.

- `totalClusters`, `connectedClusters`, `disconnectedClusters`: from the `status.connected` field of every ClusterRegistration (a registration with no status counts as disconnected)
- `totalActiveIssues`: Issues in **this** cluster, in any namespace, whose state is not `Resolved` or `Failed` (Issues of remote clusters are not counted)

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "FederationStatus",
  "spec": {
    "totalClusters": 5,
    "connectedClusters": 4,
    "disconnectedClusters": 1,
    "totalActiveIssues": 7
  }
}
```
</ResponseExample>
