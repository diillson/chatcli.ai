---
title: "Analytics MTTR"
openapi: "GET /analytics/mttr"
description: "Returns Mean Time To Resolve per day, computed from resolved Issues"
icon: "stopwatch"
---

<ParamField query="from" type="string">
  Start of the window, RFC 3339 (e.g., `2026-03-01T00:00:00Z`). An unparseable value is ignored.
</ParamField>

<ParamField query="to" type="string">
  End of the window, RFC 3339.
</ParamField>

Minimum role: `viewer`. Covers every namespace. There are no `period`, `severity`, `namespace` or `granularity` parameters, and no percentile, per-severity or per-phase breakdown.

Only Issues in state `Resolved` with `status.resolvedAt` set are counted. The resolution time is `resolvedAt − creationTimestamp`, grouped by the day the Issue was created (`YYYY-MM-DD`, ascending). In each item, `value` is the mean in **seconds** and `count` the number of Issues that day.
