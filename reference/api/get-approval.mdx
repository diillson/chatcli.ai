---
title: "Get Approval"
openapi: "GET /approvals/{name}"
description: "Returns one approval request"
icon: "magnifying-glass"
---

<ParamField path="name" type="string" required>
  Approval request name (e.g., `approval-payment-service-oom-kill-1773933600-plan-1`)
</ParamField>

<ParamField query="namespace" type="string">
  Kubernetes namespace. When omitted, every namespace is searched and the first request with that name is returned.
</ParamField>

`spec` and `status` carry the same flat approval item described in [List Approvals](/reference/api/list-approvals); `resourceMeta` carries the Kubernetes metadata. The blast radius assessment, AI evidence, `timeoutMinutes`, `requiredApprovers` and the recorded `status.decisions` are not exposed here — use `kubectl get approvalrequest <name> -o yaml`.
