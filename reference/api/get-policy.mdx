---
title: "Get Policy"
openapi: "GET /policies/{kind}/{name}"
description: "Returns one ApprovalPolicy, NotificationPolicy, EscalationPolicy or IncidentSLA with its raw spec and status"
icon: "file-lines"
---

<ParamField path="kind" type="string" required>
  `approval`, `notification`, `escalation` or `sla`
</ParamField>

<ParamField path="name" type="string" required>
  Policy name
</ParamField>

<ParamField query="namespace" type="string">
  Namespace of the policy
</ParamField>

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "IncidentSLA",
  "spec": { "severity": "critical", "responseTime": "15m", "resolutionTime": "1h" },
  "status": { "totalIssuesTracked": 14, "totalViolations": 2, "activeViolations": 1, "compliancePercentage": 85.7 }
}
```
</ResponseExample>
