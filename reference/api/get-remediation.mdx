---
title: "Get Incident Remediation"
openapi: "GET /incidents/{name}/remediation"
description: "Returns the remediation plans created for an incident, with their execution state"
icon: "wrench"
---

<ParamField path="name" type="string" required>
  Name of the Issue resource (e.g., `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="namespace" type="string">
  Only plans in this namespace. When omitted, plans from every namespace whose `issueRef` matches the name are returned.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Items per page (maximum 100)
</ParamField>

Returns every RemediationPlan whose `issueRef` is this incident — one per attempt (`<issue>-plan-1`, `<issue>-plan-2`, …) — in the same item shape as [List Remediations](/reference/api/list-remediations). An incident with no plan yet returns an empty list (`totalCount: 0`), not `404`; the incident itself is not looked up. For evidence, rollback data and the agentic history of one plan, use [Get Remediation Plan](/reference/api/get-remediation-detail).
