icon: "chart-pie"

<ParamField query="from" type="string">
  Start of the window, RFC 3339 (e.g., `2026-03-01T00:00:00Z`). An unparseable value is ignored.
</ParamField>

<ParamField query="to" type="string">
  End of the window, RFC 3339.
</ParamField>

## Calculation Methodology

Minimum role: `viewer`. Covers every namespace. RemediationPlans created in the window are grouped by their **parent Issue**, and success is judged by the **Issue's current state**, not by each plan:

- **Successful**: the parent Issue is `Resolved`
- **Failed**: the parent Issue is in any other state (including Issues still being remediated)

So an Issue whose first two plans failed and third plan resolved it counts as one success. Each Issue counts **once per strategy** it used.

The strategy label (`action`) is:

- in agentic mode, the plan's `strategy` field (the operator sets `Agentic AI-driven remediation`), or else the first action type in its history, or else `Agentic`;
- otherwise, the type of the plan's first action, or `Unknown` when it has none.

`successRate` is a ratio from 0 to 1. `avgDuration` is in **seconds**, averaged over plans that have both `startedAt` and `completedAt`. Items are sorted by `total`, highest first.

<Note>
Plans whose parent Issue no longer exists are excluded. Plans still in progress are counted: their Issue is not `Resolved` yet, so they count as failures until it is.
</Note>
