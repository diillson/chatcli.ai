---
title: "Federation Clusters"
openapi: "GET /federation/clusters"
description: "Returns every federated cluster, optionally filtered by tier"
icon: "list"
---

<ParamField query="tier" type="string">
  Filter by `spec.tier`: `critical`, `standard`, `non-critical` (exact match)
</ParamField>

Minimum role: `viewer`. Lists ClusterRegistrations of every namespace. The response is **not** paginated: `metadata.page` is `1` and `pageSize` equals the number of items. Item fields are described in [List Clusters](/reference/api/list-clusters).
