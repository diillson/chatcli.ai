---
title: "Get Incident"
openapi: "GET /incidents/{name}"
description: "Returns the full details of a specific incident"
icon: "magnifying-glass"
---

<ParamField path="name" type="string" required>
  Name of the Issue resource (e.g., `payment-service-oom-kill-1773933600`). The short `INC-YYYYMMDD-NNN` id is only the `platform.chatcli.io/inc-id` label, not the name.
</ParamField>

<ParamField query="namespace" type="string">
  Namespace of the incident. When omitted, every namespace is searched and the first incident with that name is returned.
</ParamField>

`spec` and `status` carry the same incident object (the fields of [List Incidents](/reference/api/list-incidents)); `resourceMeta` carries the Kubernetes metadata, including annotations. The AI analysis is not embedded — fetch it with [Get AI Insight](/reference/api/get-aiinsight) (`<name>-insight`).
