---
title: "Federation Correlations"
openapi: "GET /federation/correlations"
description: "Returns cross-cluster issue correlations read from Issue annotations"
icon: "diagram-project"
---

Minimum role: `viewer`. Takes no parameters. Lists the Issues of this cluster that carry the annotation `platform.chatcli.io/correlation-id`, one item per distinct correlation ID.

## Correlation Fields

| Field | Source |
|-------|--------|
| `correlationId` | Annotation `platform.chatcli.io/correlation-id` |
| `issue`, `namespace`, `severity`, `signalType` | The first Issue seen with that ID |
| `correlatedClusters` | Raw value of the annotation `platform.chatcli.io/correlated-clusters` |
| `elevated` | Annotation `platform.chatcli.io/elevated-severity` is `"true"` |
| `cascade` | Annotation `platform.chatcli.io/cascade-detected` is `"true"` |

<Warning>
**Known limitation: this endpoint returns an empty list in current releases.** The federation controller does not write the annotations it reads. When the same `signalType` is active in 3 or more clusters, `CorrelateAcrossClusters` sets `platform.chatcli.io/cross-cluster-correlation` (`xcluster-<id>`) and `platform.chatcli.io/affected-clusters` (a count) and raises `spec.severity` to `critical`; `DetectCascade` sets `platform.chatcli.io/cascade-detected`, `cascade-source-cluster` and `cascade-source-issue`. Nothing writes `correlation-id`, `correlated-clusters` or `elevated-severity`, so every Issue is skipped. Until that is fixed, find correlations directly:

```bash
kubectl get issues -A -o json | jq -r '.items[]
  | select(.metadata.annotations["platform.chatcli.io/cross-cluster-correlation"] != null
        or .metadata.annotations["platform.chatcli.io/cascade-detected"] == "true")
  | [.metadata.namespace, .metadata.name, .spec.severity,
     .metadata.annotations["platform.chatcli.io/cross-cluster-correlation"] // "-",
     .metadata.annotations["platform.chatcli.io/affected-clusters"] // "-",
     .metadata.annotations["platform.chatcli.io/cascade-source-cluster"] // "-"] | @tsv'
```
</Warning>
