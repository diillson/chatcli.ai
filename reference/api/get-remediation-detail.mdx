---
title: "Get Remediation Plan"
openapi: "GET /remediations/{name}"
description: "Returns complete remediation plan details including execution evidence, rollback info, safety constraints, and agentic conversation history"
icon: "wrench"
---

<ParamField path="name" type="string" required>
  Remediation plan name, `<issue>-plan-<attempt>` (e.g., `checkout-api-error-rate-1773932940-plan-1`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Kubernetes namespace. Defaults to `default` (it does not search other namespaces), so pass the plan's namespace explicitly.
</ParamField>

## Response Details

`spec` is the list item extended with the fields below; `status` is the plan's raw Kubernetes status (including `preflightSnapshot`, `actionCheckpoints`, `actionsCompletedAt` and `postFailureHealthy` when set).

| Field | Description |
|-------|-------------|
| `safetyConstraints` | Constraints that must be respected during execution |
| `evidence` | Evidence recorded during execution (`preflight_snapshot`, `action_completed`, `action_failed`, `verification_passed`, `verification_failed`, `rollback`, …) |
| `rollbackPerformed` | Whether automatic rollback was triggered |
| `rollbackResult` | Outcome of the rollback attempt |
| `agenticHistory` | Step-by-step AI reasoning and actions (agentic mode only) |

### Agentic History

When `agenticMode` is true, the `agenticHistory` array shows the complete AI conversation:

- **`aiMessage`**: The AI's reasoning for each step
- **`action`**: The concrete action proposed (omitted for an observation-only step)
- **`observation`**: The result after executing the action
- **`stepNumber`**: Sequential step number

This is the key data for understanding **how the AI thought** through the remediation process.
