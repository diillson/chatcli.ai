---
title: "Get SLO"
openapi: "GET /slos/{name}"
description: "Returns a single ServiceLevelObjective"
icon: "gauge"
---

<ParamField path="name" type="string" required>
  SLO name (e.g., `payment-availability`)
</ParamField>

<ParamField query="namespace" type="string">
  Namespace of the SLO. When omitted, every namespace is searched and the first SLO with that name is returned.
</ParamField>

Minimum role: `viewer`. `spec` and `status` carry the **same** flattened object (the fields described in [List SLOs](/reference/api/list-slos)); the raw CRD is not returned. `currentValue` and `errorBudgetRemaining` are percentages, `errorBudgetTotal` and `errorBudgetUsed` are fractions. `state` (`Healthy`, `AtRisk` or `Breached`) is omitted before the controller's first calculation.
