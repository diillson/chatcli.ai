---
title: "List PostMortems"
openapi: "GET /postmortems"
description: "Returns the list of postmortems automatically generated by the platform"
icon: "list"
---

<ParamField query="namespace" type="string">
  Filter by Kubernetes namespace. Omit it to list every namespace.
</ParamField>

<ParamField query="severity" type="string">
  Filter by severity: `critical`, `high`, `medium`, `low`
</ParamField>

<ParamField query="state" type="string">
  Filter by state: `Open`, `InReview`, `Closed` (exact match)
</ParamField>

<ParamField query="from" type="string">
  Only postmortems created at or after this RFC 3339 timestamp (e.g., `2026-03-01T00:00:00Z`)
</ParamField>

<ParamField query="to" type="string">
  Only postmortems created at or before this RFC 3339 timestamp
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Items per page (maximum 100)
</ParamField>

Minimum role: `viewer`. A PostMortem is named `pm-<issue name>` and each item has the same fields as [Get PostMortem](/reference/api/get-postmortem). An unparseable `from`/`to` value is ignored.
