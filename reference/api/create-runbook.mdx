---
title: "Create Runbook"
openapi: "POST /runbooks"
description: "Creates a new Runbook resource"
icon: "plus"
---

<ParamField body="name" type="string" required>
  Runbook name (a Kubernetes resource name, e.g., `disk-cleanup`)
</ParamField>

<ParamField body="namespace" type="string" default="default">
  Namespace to create the runbook in
</ParamField>

<ParamField body="description" type="string">
  Purpose of the runbook
</ParamField>

<ParamField body="trigger" type="object" required>
  When the runbook applies. All three fields are required by the CRD.
  <Expandable title="Trigger properties">
    <ParamField body="signalType" type="string" required>
      Anomaly signal, e.g. `oom_kill`, `crashloop_backoff`, `error_rate`, `latency`, `pod_restart`, `cpu_high`, `memory_high`, `disk_pressure`, `image_pull_error` (full list in the Anomaly CRD enum)
    </ParamField>
    <ParamField body="severity" type="string" required>
      `critical`, `high`, `medium` or `low`
    </ParamField>
    <ParamField body="resourceKind" type="string" required>
      Kind of the affected resource, e.g. `Deployment`, `StatefulSet`, `DaemonSet`, `Job`, `CronJob`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="steps" type="object[]" required>
  Ordered steps
  <Expandable title="Step properties">
    <ParamField body="name" type="string" required>
      Step name
    </ParamField>
    <ParamField body="action" type="string" required>
      Remediation action type, e.g. `AdjustResources`, `RestartDeployment`, `ScaleDeployment`, `RollbackDeployment`, `ExecDiagnostic`
    </ParamField>
    <ParamField body="description" type="string">
      Why the step is needed and what it does
    </ParamField>
    <ParamField body="params" type="object">
      String key/value parameters for the action (e.g. `{"memory_limit": "1Gi"}`, `{"replicas": "5"}`)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="maxAttempts" type="integer" default="3">
  Maximum number of remediation attempts; 0 or omitted means 3
</ParamField>

<ParamField body="labels" type="object">
  Kubernetes labels for the Runbook
</ParamField>

The response is `201 Created` with the runbook in `spec` and its metadata in `resourceMeta`. A missing `name` or malformed JSON returns `400`; a Kubernetes API failure returns the API server's message with a status that matches it: `409` only when a runbook with that name already exists, `422` when the API server rejects the object (a value outside the CRD enums, a missing required field), `403` when the operator may not create it, and `500` otherwise.

<RequestExample>
```json runbook.json
{
  "name": "disk-cleanup",
  "namespace": "production",
  "description": "Free disk space when a StatefulSet reports disk pressure",
  "trigger": {
    "signalType": "disk_pressure",
    "severity": "medium",
    "resourceKind": "StatefulSet"
  },
  "steps": [
    {
      "name": "diagnose",
      "action": "ExecDiagnostic",
      "description": "Check filesystem usage",
      "params": {
        "command": "df -h"
      }
    },
    {
      "name": "restart-pod",
      "action": "RestartStatefulSetPod",
      "description": "Restart the affected pod"
    }
  ],
  "labels": {
    "team": "storage"
  }
}
```

```bash curl
curl -X POST -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d @runbook.json http://localhost:8090/api/v1/runbooks
```
</RequestExample>
