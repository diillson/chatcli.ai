---
title: "Delete Runbook"
openapi: "DELETE /runbooks/{name}"
description: "Deletes a Runbook resource. Requires the admin role."
icon: "trash"
---

<ParamField path="name" type="string" required>
  Runbook name (e.g., `disk-cleanup`)
</ParamField>

<ParamField query="namespace" type="string" default="default">
  Namespace of the runbook (other namespaces are not searched)
</ParamField>

Requires the **`admin`** role. The runbook is deleted without any in-use check: RemediationPlans already created from it keep their own copy of the actions and are not affected.

<ResponseExample>
```json Response 200
{
  "apiVersion": "v1",
  "kind": "Status",
  "status": "deleted",
  "name": "disk-cleanup"
}
```
</ResponseExample>

<ResponseExample>
```json Response 404
{
  "apiVersion": "v1",
  "kind": "Error",
  "error": "Not Found",
  "code": 404,
  "message": "runbook not found: runbooks.platform.chatcli.io \"disk-cleanup\" not found"
}
```
</ResponseExample>
