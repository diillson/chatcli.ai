---
title: "Acknowledge Incident"
openapi: "POST /incidents/{name}/acknowledge"
description: "Marks an incident as acknowledged by adding annotations to the Issue"
icon: "check"
---

<ParamField path="name" type="string" required>
  Name of the Issue resource (e.g., `payment-service-oom-kill-1773933600`)
</ParamField>

<ParamField query="namespace" type="string">
  Namespace of the incident. When omitted, every namespace is searched (first match).
</ParamField>

No request body is read. The call adds three annotations to the Issue and returns the updated incident:

| Annotation | Value |
|:-----------|:------|
| `aiops.chatcli.io/acknowledged` | `"true"` |
| `aiops.chatcli.io/acknowledged-at` | Current time (RFC 3339) |
| `aiops.chatcli.io/acknowledged-by` | The **role** of the calling API key (`operator` or `admin`) — not a person's name |

<Note>
Acknowledging is only a marker (visible in the incident's `annotations`; the dashboard does not display it): it does not change the incident `state`, and no controller reads these annotations (escalation and notifications are not paused by it). Acknowledging again simply refreshes the timestamp; there is no conflict error.
</Note>
