---
title: "Get Cluster"
openapi: "GET /clusters/{name}"
description: "Returns one ClusterRegistration with its health status, node count and active incidents"
icon: "diagram-project"
---

<ParamField path="name" type="string" required>
  ClusterRegistration name
</ParamField>

<ParamField query="namespace" type="string">
  Namespace where the ClusterRegistration lives. When omitted, every namespace is searched.
</ParamField>

Minimum role: `viewer`. `spec` and `status` carry the **same** flattened object (see [List Clusters](/reference/api/list-clusters) for the fields). The kubeconfig Secret reference, health-check interval, capabilities and conditions are not returned; use `kubectl get clusterregistration <name> -o yaml` for those.
