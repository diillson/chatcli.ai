---
title: "Export Audit"
openapi: "GET /audit/export"
description: "Downloads the filtered AuditEvent records as one JSON file for compliance and SIEM ingestion"
icon: "file-export"
---

<ParamField query="namespace" type="string">
  Filter by the namespace of the AuditEvent. Omit it to list every namespace.
</ParamField>

<ParamField query="type" type="string">
  Filter by `eventType` (exact match), e.g. `issue_created`, `issue_resolved`, `issue_escalated`, `issue_contained`, `remediation_started`, `remediation_completed`, `remediation_failed`, `approval_requested`, `approval_approved`, `approval_rejected`, `approval_expired`, `notification_sent`, `slo_violation`, `sla_breach`
</ParamField>

<ParamField query="severity" type="string">
  Filter by severity: `info`, `warning`, `critical`
</ParamField>

<ParamField query="resource" type="string">
  Filter by the affected resource **name** (exact match on `resourceName`)
</ParamField>

<ParamField query="from" type="string">
  Only events at or after this RFC 3339 timestamp (`spec.timestamp`, falling back to the creation time)
</ParamField>

<ParamField query="to" type="string">
  Only events at or before this RFC 3339 timestamp
</ParamField>

Minimum role: `viewer`. Takes the same filters as [List Audit Events](/reference/api/list-audit), but returns **every** matching event in one synchronous `200` response, with no pagination. The body is JSON only (there is no CSV or `format` option and no asynchronous export job), sent with `Content-Disposition: attachment; filename=audit-events-<YYYYMMDD-HHMMSS>.json`.

```bash
curl -s -H "X-API-Key: $CHATCLI_API_KEY" \
  "http://localhost:8090/api/v1/audit/export?namespace=production&from=2026-03-01T00:00:00Z" \
  -o audit-events.json
```
